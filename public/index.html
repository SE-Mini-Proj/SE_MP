Room Settings & RBAC

Owners and moderators can mute, ban, or kick members. Actions create immutable audit logs.

Transport Security (CHAT-SR-001)

TLS 1.2+ encryption is mandatory. Plaintext ws:// and http:// connections are rejected via strict middleware validation.

Cross-Site Scripting (CHAT-SR-004)

All incoming messages are sanitized via sanitizeMessage(). HTML tags and malicious event payloads are neutralized safely before broadcast.

Role-Based Access Control (CHAT-SR-005)

Moderation actions are enforced by requireRoomRole([OWNER, ADMIN, MODERATOR]). Unprivileged requests return HTTP 403 Forbidden.

Redis Scalability & Presence

Redis Pub/Sub multiplexes cross-instance messaging and heartbeat presence tracking across concurrent cluster nodes.
